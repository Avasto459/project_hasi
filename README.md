# HASI.TJ

Интернет-магазин камер видеонаблюдения и оборудования для безопасности. Категории, товары, остатки, цены и заказы хранятся в SQLite; цены в базе задаются целыми числами в сомони (TJS).

## Локальный запуск

Требуются Node.js и npm.

1. Установите зависимости: `npm install`
2. Скопируйте `.env.example` в `.env.local`.
3. Задайте уникальные значения `JWT_SECRET` (не менее 32 символов), `HASI_ADMIN_EMAIL` и `HASI_ADMIN_PASSWORD` (не менее 12 символов).
4. Запустите `npm run dev` и откройте http://localhost:3000.

При первом запуске создаются категории видеонаблюдения, пустой каталог и настроенная учётная запись администратора. Тестовые товары и фиксированные цены не создаются. Администратор добавляет фактические товары, артикулы, бренды, цены и остатки в панели `/admin`.

SQLite по умолчанию хранится в `data/hasi.db`. Путь можно изменить переменной `HASI_DATABASE_PATH`. Старые служебные данные заказов предыдущей версии сохраняются в таблице `orders_legacy`; ранее предзаполненные демонстрационные товары удаляются при миграции.

## Основные сценарии

- Поиск: `GET /api/products?search=камера`; поиск охватывает название, описание, категорию, артикул и бренд.
- Гостевая корзина сохраняется в браузере; корзина авторизованного пользователя хранится в базе.
- Заказ создаётся через `POST /api/orders`; цены, наличие и итоговая сумма проверяются сервером в транзакции.
- Панель `/admin` защищена проверкой JWT и роли в API; администратор управляет категориями, товарами, остатками и заказами.
- Заявки формы контактов сохраняются в базе и доступны администратору.

Проверки проекта: `npm run build` и `npm run lint`.
