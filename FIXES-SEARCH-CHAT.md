# Исправления поиска и онлайн-чата

- Добавлен защищённый маршрут `/admin/users`, открывающий вкладку управления пользователями и дилерами.
- Поиск пользователей ищет по имени, фамилии, email, телефону (в том числе по цифрам без форматирования) и ID.
- В `/admin/orders` добавлен клиентский поиск по номеру заявки, покупателю, дилеру, телефону, адресу/комментарию и названиям товаров; фильтр по статусу сохранён.
- Поиск каталога обновляет query-параметр с debounce 300 мс и сохраняет выбранные фильтры.
- Виджет онлайн-чата больше не скрывается, когда у пользователя ещё нет обращений. Гость может указать имя и телефон и отправить сообщение; авторизованный пользователь использует свою сессию.
- Сообщения отправляются через существующий `/api/contact`, сохраняются в базе, получают visitor token, а история/ответы загружаются через `/api/messages` с опросом каждые 5 секунд.

## Проверка
Синтаксис изменённых TypeScript/TSX файлов проверен через TypeScript transpileModule. Полная сборка Next.js не выполнена: установка зависимостей в текущем окружении не завершилась корректно. Перед публикацией выполнить `npm ci` и `npm run build`.
